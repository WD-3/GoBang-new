【问题诊断 / Problem Diagnosis】
--------------------------------------------------------------------------------

用户报告的严重问题：
1. ❌ Temperature 形同虚设 - 调节后棋局毫无变化
2. ❌ 每局棋完全一样 - 循环三局，每一局都一模一样
3. ❌ 第六颗黑棋卡死 - 每次都到同一位置卡住
4. ❌ 棋子闪现复现 - 重新开始后棋子按原路线下两颗后直接结束

根本原因/Root Causes:
1. ❌ Temperature 参数没有传递到 LLM 玩家创建函数
2. ❌ 游戏结束后没有清理，导致 LLM 玩家对象被复用
3. ❌ 白方内存数据收集缩进错误（在 if 块外）
4. ❌ 网页端没有发送 temperature 参数到后端

✅ 修复 4: 白方内存数据收集缩进
   文件：gobang/templates/index.html
   位置：第 1883-1884 行
   
   修改内容:
   - 将白方内存收集代码移入 if 块内
   - 确保只在白方回合时收集数据
   
   修改前:
   ```javascript
   if (perf.gpu_available) {
       if (currentStone === 'BLACK') {
           // 黑方数据收集
       } else {
           // 白方 GPU 数据收集
       }
   }
   batchStats.whiteMemTotal += perf.memory_percent;  // ← 错误：在 if 外
   batchStats.whiteMemSamples++;                      // ← 错误：在 if 外
   ```
   
   修改后:
   ```javascript
   if (perf.gpu_available) {
       if (currentStone === 'BLACK') {
           // 黑方数据收集
           batchStats.blackMemTotal += perf.memory_percent;
           batchStats.blackMemSamples++;
       } else {
           // 白方数据收集
           batchStats.whiteMemTotal += perf.memory_percent;
           batchStats.whiteMemSamples++;
       }
   }
   ```

【重启步骤 / Restart Steps】
--------------------------------------------------------------------------------

1. 停止当前服务器
   按 Ctrl+C 停止运行中的服务器

2. 重新启动服务器
   .venv\Scripts\python.exe -m gobang web --port 5000

3. 观察启动日志
   应该看到类似以下输出:
   Starting GoBang web server at http://127.0.0.1:5000
   Version: 1.1.0

4. 测试 Temperature 调节
   - 打开浏览器访问 http://127.0.0.1:5000
   - 进入"机机对抗"模式
   - 选择两个相同的 4B 模型（如 qwen3-4b vs qwen3-4b）
   - 设置 Temperature=0.5
   - 开始循环对战（3 局）
   - 观察每局棋是否不同

5. 测试 Temperature 变化
   - 调整 Temperature 滑块到 0.3
   - 重新开始循环对战
   - 观察棋局变化是否减少
   - 调整 Temperature 到 0.8
   - 重新开始循环对战
   - 观察棋局变化是否增多

【故障排查 / Troubleshooting】
--------------------------------------------------------------------------------

问题 1: Temperature 仍然不生效
解决:
- 检查浏览器控制台（F12）是否有错误
- 确认网页端发送了 temperature 参数
- 重启服务器确保代码重新加载

问题 2: 棋局仍然完全一样
解决:
- 确认 Temperature 不为 0（0 表示确定性输出）
- 检查 Ollama 是否支持 temperature 参数
- 尝试更换不同的模型测试

问题 3: 仍然卡死在第六颗棋
解决:
- 检查 Ollama 服务是否正常运行
- 查看服务器日志是否有超时错误
- 增加超时时间（当前 120 秒）

问题 4: 游戏清理失败
解决:
- 检查浏览器控制台错误
- 确认 DELETE 请求成功
- 手动刷新页面清除状态

【技术细节 / Technical Details】
--------------------------------------------------------------------------------

Temperature 参数传递链路:
1. 网页端滑块 → document.getElementById('temperatureSlider').value
2. getModeConfig() → config.temperature
3. fetch('/api/games') → body: { temperature: config.temperature }
4. app.py api_create_game() → data.get("temperature")
5. _setup_llm_players() → config.get("temperature", 0.5)
6. create_llm_player() → temperature=temperature
7. OllamaClient / OpenAICompatibleClient → self.temperature
8. LLM API 调用 → temperature=self.temperature

游戏清理链路:
1. 局结束 → batchStats.gameResults.push()
2. 清理代码 → fetch(`/api/games/${gameId}`, { method: 'DELETE' })
3. app.py api_delete_game() → del games[game_id], del llm_players[game_id]
4. 资源释放 → Python GC 回收对象
