【一、游戏概述 / Game Overview】
--------------------------------------------------------------------------------
五子棋是一种两人对弈的纯策略型棋类游戏。
Gomoku is a pure strategy board game played by two players.

- 棋盘：15×15 网格（标准比赛规格）
  Board: 15×15 grid (standard tournament specification)
  
- 棋子：黑白两色，黑方先行
  Stones: Black and White, Black moves first
  
- 目标：先连成 5 子者获胜
  Objective: First to connect 5 stones wins

2.2 落子规则 / Move Rule
-----------------------
✓ 允许：下在任意空位 (·) 上
   Valid: Place stone on any empty position (·)

✗ 禁止：下在已有棋子的位置
   Invalid: Place stone on occupied position

✗ 禁止：下在棋盘外
   Invalid: Place stone outside the board

✗ 禁止：跳过回合
   Invalid: Skip turn

2.3 先后手规则 / Turn Order
--------------------------
1. 黑方 (●) 先行 / Black (●) moves first
2. 双方交替落子 / Players alternate turns
3. 每回合必须落子一子 / Must place exactly one stone per turn

2.4 和棋条件 / Draw Condition
----------------------------
当满足以下条件时，游戏判定为和棋：
Game is declared a DRAW when:

- 棋盘 225 个位置全部下满
  All 225 positions (15×15) are filled
  
- 且双方均未连成 5 子
  AND neither player has connected 5 stones

【四、棋型术语与定义 / Pattern Terminology】
--------------------------------------------------------------------------------

4.1 五连 / Five (GAME WIN)
-------------------------
定义：连续 5 个同色棋子相连
Definition: 5 consecutive stones of same color connected

示例：
    ●●●●●  ← 五连，立即获胜！
    
状态：游戏结束，该玩家获胜
Status: GAME OVER, this player WINS

4.2 活四 / Open Four (★★★★★ 极高威胁)
------------------------------------
定义：4 子相连，且两端都是空位
Definition: 4 stones connected, BOTH ends are empty

示例：
    ·●●●●·  ← 活四
    
威胁等级：致命 / Lethal
应对：
  - 进攻方：下一步必然成五连获胜
    Attacker: Next move will definitely form 5-in-a-row and WIN
  - 防守方：必须立即阻挡，但已无法阻止（两端都能成五）
    Defender: Must block immediately, but cannot stop (both ends work)

4.3 冲四 / Rush Four (★★★★ 高威胁)
----------------------------------
定义：4 子相连，但一端已被堵住
Definition: 4 stones connected, but ONE end is blocked

示例：
    ·●●●●○  ← 冲四（右端被堵）
    ○●●●●·  ← 冲四（左端被堵）
    
威胁等级：高 / High
应对：
  - 进攻方：下一步可成五连
    Attacker: Can form 5-in-a-row next move
  - 防守方：必须在空的一端阻挡
    Defender: Must block at the empty end

4.4 活三 / Open Three (★★★ 中等威胁)
------------------------------------
定义：3 子相连，且两端都是空位
Definition: 3 stones connected, BOTH ends are empty

示例：
    ·●●●·  ← 活三
    
威胁等级：中等 / Medium
应对：
  - 进攻方：可发展为活四或冲四
    Attacker: Can develop into open-four or rush-four
  - 防守方：应考虑阻挡，否则可能形成四连
    Defender: Should consider blocking, or opponent may form 4-in-a-row

4.5 眠三 / Sleep Three (★★ 低威胁)
----------------------------------
定义：3 子相连，但一端已被堵住
Definition: 3 stones connected, but ONE end is blocked

示例：
    ·●●●○  ← 眠三
    ○●●●·  ← 眠三
    
威胁等级：低 / Low
应对：
  - 进攻方：需要继续发展
    Attacker: Needs to continue developing
  - 防守方：可以暂时不处理，优先处理更大威胁
    Defender: Can temporarily ignore, prioritize bigger threats

4.6 活二 / Open Two (★ 潜在威胁)
--------------------------------
定义：2 子相连，且两端都是空位
Definition: 2 stones connected, BOTH ends are empty

示例：
    ·●●·  ← 活二
    
威胁等级：低 / Low
说明：早期布局阶段常见，需要继续发展
Note: Common in opening stage, needs further development

【七、常见错误与避免 / Common Mistakes to Avoid】
--------------------------------------------------------------------------------

❌ 错误 1：无视对手四连
   Mistake 1: Ignoring opponent's 4-in-a-row
   后果：立即输棋
   Consequence: Immediate loss
   
   ✓ 正确：发现对手四连必须立即阻挡
   ✓ Correct: Must block immediately when opponent has 4-in-a-row

❌ 错误 2：有获胜机会不赢
   Mistake 2: Not winning when opportunity exists
   后果：错失必胜局面
   Consequence: Miss winning position
   
   ✓ 正确：优先检查己方是否能成五连
   ✓ Correct: Always check if you can form 5-in-a-row first

❌ 错误 3：乱下边角
   Mistake 3: Randomly playing corners/edges
   后果：失去中心控制权
   Consequence: Lose center control
   
   ✓ 正确：前期抢占中心，后期根据局势
   ✓ Correct: Control center early, adapt later

❌ 错误 4：不连自己的子
   Mistake 4: Not connecting own stones
   后果：棋子分散，无法形成威胁
   Consequence: Scattered stones, no threats
   
   ✓ 正确：尽量靠近己方棋子落子
   ✓ Correct: Play near own stones when possible

❌ 错误 5：不挡对手活三
   Mistake 5: Not blocking opponent's open-three
   后果：对手发展成活四，难以防守
   Consequence: Opponent develops open-four, hard to defend
   
   ✓ 正确：对手活三应考虑阻挡
   ✓ Correct: Consider blocking opponent's open-three
